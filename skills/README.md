# 开源 Skills

可上传到平台的巡检、测评、处置与 SRE 技能。脚本包上传对应压缩包，文档型技能上传 `SKILL.md`。

SRE 技能可按这些词搜索：SLO、SLI、错误预算、error budget、黄金信号、golden signals、故障应急、incident、MTTR、复盘、postmortem、值班交接、on-call。
