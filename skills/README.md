| `open-skill-network-patrol` | 脚本包 | `网络设备巡检.zip` |
| `open-skill-k8s-load` | 脚本包 | `K8s负载检测与处理.zip` |

| `open-skill-redis-oom` | 纯文档 | `SKILL.md` |
| `open-skill-alert-storm` | 纯文档 | `SKILL.md` |
