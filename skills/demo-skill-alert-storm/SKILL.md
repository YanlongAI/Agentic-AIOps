# 告警风暴降噪处置（文档型 Skill）

## 何时使用

- 5～15 分钟内同类告警暴增，值班被刷屏
- 同一主机/同一业务组多指标同时触发
- 用户要求「先降噪再说根因」

**不适用**：单条 P0 且已确认真实故障（应走 RCA / 处置，而不是抑制）。

## 执行规则

1. 先读本文档，再查告警列表与业务组拓扑。
2. 禁止未经确认的批量「忽略关闭」生产告警。
3. 任何抑制策略需说明窗口与回滚方式。

## 推荐流程

1. **收敛**：按实例 / 业务组 / 指标族聚合，找出 Top 噪声源
2. **初判**：区分瞬时毛刺、容量缓增、真实故障（可结合 AI 风险预测 / 形态标签）
3. **临时降噪**（需确认）：合并窗口、同类抑制、下调非关键指标灵敏度
4. **根因入口**：对真正故障单跳转 RCA 或 ChatOps 深挖
5. **复盘**：记录噪声来源与是否固化到告警策略

## 输出要求

- 噪声占比与 Top 源
- 已采取措施与有效期
- 待跟进的真实故障单号
